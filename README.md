# Yulu Bike Rental Analysis – Hypothesis Testing

## Project Overview
This project analyzes Yulu bike rental data to understand the factors affecting rental demand. Statistical analysis and hypothesis testing are used to identify relationships between weather conditions, seasons, working days, and bike rentals.

## Business Objectives
- Understand bike rental demand patterns.
- Analyze the impact of weather conditions on rentals.
- Compare rentals on working days and holidays.
- Identify seasonal differences in rental demand.
- Provide data-driven business recommendations.

## Dataset Information
- **Rows:** 10,886
- **Columns:** 12
- **Missing Values:** None reported in the analysis.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Statistical Hypothesis Testing

## Analysis Performed
- Data cleaning and exploratory data analysis (EDA)
- Univariate and bivariate analysis
- Two-Sample T-Test
- ANOVA
- Chi-Square Test
- Statistical visualization
- Business insights and recommendations

## Key Findings
- Bike rental counts show a right-skewed distribution.
- Rental demand varies across seasons.
- Working days are associated with differences in rental patterns.
- Weather conditions are associated with bike rental demand.

## Business Recommendations
- Adjust bike availability according to seasonal demand.
- Use weather conditions to support demand planning.
- Optimize bike distribution based on working-day rental patterns.
- Use data-driven insights to improve operational planning.
